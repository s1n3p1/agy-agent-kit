# Technical Research

1. Define the exact question, product/version, and freshness requirement.
2. Prefer primary sources and installed built-in documentation for the installed product version.
3. Capture version/date for claims that can change over time.
4. Separate current behavior, historical behavior, and inference.
5. Cross-check high-impact claims when sources conflict.
6. When installed built-in docs conflict with public web docs, prioritize the installed version and verify runtime discovery when possible.
7. Summarize only what the evidence supports.
