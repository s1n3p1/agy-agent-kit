# Frontend UI

1. Inspect the existing component, design system, CSS strategy, and responsive breakpoints.
2. Identify the exact visual or interaction problem before restructuring.
3. Prefer local layout and spacing fixes over broad redesign.
4. Preserve information hierarchy and interaction behavior unless redesign is requested.
5. Reuse existing tokens, utilities, primitives, and component patterns.
6. Check representative mobile and desktop widths.
7. Verify overflow, text wrapping, touch targets, focus behavior, and obvious accessibility regressions.
8. When browser/screenshot tooling is available, compare the changed result with the requested visual outcome.
9. Apply the global completion gate.
