# Bug Investigation

1. Apply the evidence mandate from the global AGY Agent Kit bootstrap.
2. Reproduce or capture the exact failure and complete relevant evidence.
3. Trace the responsible code/configuration path.
4. Separate observed facts from inference.
5. Form a falsifiable hypothesis and test it before editing.
6. Implement the smallest evidence-supported fix.
7. Add a regression test when practical.
8. Re-run the original failing path.
9. Run adjacent checks when a shared boundary changed.
10. Apply the global completion gate before reporting success.
