# Session and Scope Discipline

Load for multi-step or cross-cutting work.

## Start

1. Re-read the user's requested outcome.
2. Inspect the smallest set of repository files needed to understand the task.
3. Inspect applicable Git state before edits.
4. Identify constraints already defined by shared instructions or repository configuration.
5. Decide whether a short plan is actually needed.

Use a short explicit plan when work has dependent steps, crosses multiple modules/layers, changes architecture/schema/auth/deployment/infrastructure, has material ambiguity, or the user asks for a plan.

Do not create planning ceremony for trivial edits.

## During work

- Keep scope tied to the request.
- Re-check assumptions when evidence contradicts the plan.
- Do not silently broaden the task.
- Avoid redundant file reads when the content is already in active context.

## End

Apply the completion gate in the global AGY Agent Kit block before declaring completion.
